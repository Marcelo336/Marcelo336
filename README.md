### Olá! Eu sou o Marcelo 👋

Sou um **desenvolvedor Full Stack** em formação e apaixonado por transformar ideias em soluções digitais robustas e eficientes. Atualmente, estou focado em aprofundar meus conhecimentos e habilidades em um ecossistema moderno de desenvolvimento web.

Minha jornada tem me levado a explorar e dominar tecnologias como:

*   **Frontend:** `HTML`, `CSS` (com `Tailwind CSS` e `Styled Components`), `JavaScript`, `React.js` (com `Vite` para builds rápidos) e, crucialmente, `TypeScript` para tipagem estática e código mais seguro.

*   **Backend:** `Node.js` (utilizando os frameworks `Fastify` e `Express.js`), `TypeScript`, `Prisma ORM`, `Sequelize ORM` e `Mongoose ODM` para interação eficiente com bancos de dados.

*   **Bancos de Dados:** `MongoDB Atlas` (NoSQL), `PostgreSQL` (Relacional).

*   **Containerização:** `Docker` e `Docker Compose` para ambientes de desenvolvimento e deploy.

*   **Autenticação e Serviços:** `Firebase Authentication` (para login de usuários) e `Firebase Admin SDK` (para validação de tokens no backend).

*   **Versionamento:** `Git` e `GitHub` para controle de versão e colaboração.

Recentemente, desenvolvi o **DevBills**, um aplicativo completo de gestão financeira pessoal. Este projeto me permitiu aplicar todas as tecnologias mencionadas, desde a autenticação de usuários, gerenciamento de transações e visualização de dados com gráficos interativos, até a criação de uma API RESTful robusta.

*   [Repositório DevBills Frontend](https://github.com/Marcelo336/devbills-interface) 

*   [Repositório DevBills Backend](https://github.com/Marcelo336/devbills-api) 

Também construí o **DevBurguer**, um sistema **full-stack** de delivery de lanches. No frontend, utilizei `React.js` com `Vite` e estilização via `Styled Components` para uma interface reativa e moderna. No backend, aprofundei minhas habilidades com `Node.js` e `Express.js`, gerenciando dados de produtos, categorias e usuários em `PostgreSQL` (com `Sequelize ORM`) e `MongoDB` (com `Mongoose ODM`). Um grande destaque foi a **containerização completa da aplicação com Docker e Docker Compose**, orquestrando tanto o frontend quanto o backend e seus bancos de dados em um ambiente robusto e escalável.

*   [Repositório DevBurguer Frontend](https://github.com/Marcelo336/devburguer-interface) 

*   [Repositório DevBurguer Backend](https://github.com/Marcelo336/test-burguer-api) 

Durante o desenvolvimento desses projetos, enfrentei e superei diversos desafios complexos, como:

*   Configuração e depuração de autenticação com Firebase no frontend e backend.

*   Resolução de problemas de CORS e políticas de segurança de navegador.

*   Otimização de builds com Vite e integração de Tailwind CSS e Styled Components.

*   Gerenciamento de variáveis de ambiente e segurança de credenciais em repositórios públicos.

*   Depuração e resolução de problemas de Git, incluindo a reescrita de histórico para segurança.

*   Orquestração de ambientes multi-serviços com Docker Compose e depuração de bancos de dados relacionais (PostgreSQL/Sequelize) e NoSQL (MongoDB/Mongoose).

*   Implementação de CRUDs completos e upload de imagens.

Estou sempre em busca de novos aprendizados e oportunidades para aplicar minhas habilidades em projetos desafiadores.

Conecte-se comigo!
