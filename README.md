### Olá! Eu sou o Marcelo 👋

Sou um **desenvolvedor Full Stack** em formação e muito interessado em transformar ideias em soluções digitais robustas e eficientes. Atualmente, estou focado em aprofundar meus conhecimentos e habilidades em um ecossistema moderno de desenvolvimento web.

Minha jornada tem me levado a explorar e dominar tecnologias como:

*   **Frontend:** `HTML`, `CSS` (com `Tailwind CSS`), `JavaScript`, `React.js` (com `Vite` para builds rápidos) e, crucialmente, `TypeScript` para tipagem estática e código mais seguro.
*   **Backend:** `Node.js` (utilizando o framework `Fastify` para APIs de alta performance), `TypeScript` e `Prisma ORM` para interação eficiente com bancos de dados.
*   **Bancos de Dados:** `MongoDB Atlas` para persistência de dados NoSQL.
*   **Autenticação e Serviços:** `Firebase Authentication` (para login de usuários) e `Firebase Admin SDK` (para validação de tokens no backend).
*   **Versionamento:** `Git` e `GitHub` para controle de versão e colaboração.

Recentemente, desenvolvi o **DevBills**, um aplicativo completo de gestão financeira pessoal. Este projeto me permitiu aplicar todas as tecnologias mencionadas, desde a autenticação de usuários, gerenciamento de transações e visualização de dados com gráficos interativos, até a criação de uma API RESTful robusta.

Durante o desenvolvimento do DevBills, enfrentei e superei diversos desafios complexos, como:
*   Configuração e depuração de autenticação com Firebase no frontend e backend.
*   Resolução de problemas de CORS e políticas de segurança de navegador.
*   Otimização de builds com Vite e integração de Tailwind CSS.
*   Gerenciamento de variáveis de ambiente e segurança de credenciais em repositórios públicos.
*   Depuração e resolução de problemas de Git, incluindo a reescrita de histórico para segurança.

Estou sempre em busca de novos aprendizados e oportunidades para aplicar minhas habilidades em projetos desafiadores.

Conecte-se comigo!
